## Antigravity Agent

### Core Components

- Reasoning model
- Tools
- Artifacts
- Knowledge

### Customizations

- Agent Modes / Settings
- MCP
- Rules / Workflows

### Agent設定

- 快速設定：右下角（Antigravity Setting）
- 進階設定：進入快速設定 Advanced Setting

## 記事

- agy裡的設定分為 VSCode與agy兩種設定模式
- Workflows就是可重複使用的prompts
- 新增 rules 會跳出視窗讓你選active mode
- agy的user rules在 `~\.gemini\GEMINI.md`，不是在 `~\.antigravity`
- 工件（Artifacts）：工件是代理程式為實現更豐富對話體驗所產生的文件。
- VIX市場沒有微軟 WSL插件，直接使用wsl路徑開啟的方式，參考 [[WSL2]]

- 問題：在WSL使用agy會導致git無法監控變動  
  方法一：使用 ssh 方式連線  
  方法二：將專案移到 Windows
