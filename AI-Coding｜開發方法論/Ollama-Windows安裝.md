
## FAQs

- LLM下載好時，如何讓Ollama不載入Model  
  A：使用空字串傳送就會下載 model，下載完成後會自行load。
  
## Notes

- 模型的容量會全部載入到記憶體（電腦記憶體或是GPU記憶體）
- [Chat－ollama與記憶體關係](https://claude.ai/chat/2ee6fc5a-980f-4f6e-b9d9-f843a0ffa51c)

## 單機安裝步驟

1. 設定 Administrator 帳號的密碼
2. 開啟 Windows RDP
3. 安裝 Ollama（安裝檔）
4. 設定 Ollama  
   - 開啟網路外部訪問
   - 地端模型路徑設定
