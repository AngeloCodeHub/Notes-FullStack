
## Link

- wikilink，github無法使用  
  解決方法：使用 markdown 連結  
  設定→檔案與連結→使用wikilink。關閉  
- Markdown 連結是以相對路徑，對於寫部落格比較有用，但是要處理檔名空白鍵問題
- 實務上markdown link與wikilink可以混合使用並且都會自動更新連結
- markdown link可以用vault或文件的相對位置，關閉wikilink會自動以文件相對位置而不是以 vault root的位置
- 可以使用 `file:///d:/WorkSpace/Learn-Supabase/Untitled-1.ps1`

## Obsidian URI

Obsidian URI是跨 vault 或跳脫Obsidian的連結

- Obsidian主程式後面接 URI
  需要新增Obsidian主程式環境變數或 PowerShell Alias
- windows 檔案總管可以使用
- 可以直接瀏覽器使用（安裝 Obsidian後已經有註冊網址）
- 自動化應用
