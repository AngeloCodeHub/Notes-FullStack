### Bun

- Bun全域套件位於家目錄（包含Packages.json）
- 套件實體路徑（Windows），執行檔  
  `c:\Users\user\.bun`  
- 移除套件，其二進位bin檔會殘留

### pnpm

- pnpm幫助
  ```PowerShell
  pnpm help -a
  ```
- [Chat－pnpm套件儲存位置](https://gemini.google.com/app/735b2c8469eb1bea)
- 套件儲存於相同磁碟  
  `d:\.pnpm-store`  
  `C:\Users\user\AppData\Local\pnpm\store`
- 清除過期的套件，每個磁碟個要執行一次（因pnpm是採用硬連結）  
  `pnpm store prune`
- repo裡corepack升級pnpm
  ```PowerShell
  corepack use pnpm@10.25.0
  ```
- package.json位置  
  `C:\Users\user\AppData\Local\pnpm\global\5`

### 雜記

- 使用 Bun 安裝@react/type在next.js build會跳類型錯誤，next.js最好還是使用npm或是pnpm
- pnpm dlx shadcn@latest add dropdown-menu  
  不安裝套件直接線上執行
- pnpm 列印全域nodemudule路徑  
  `pnpm root -g`
- pnpm add與install差別：add不會安裝重複的packages，install會把該套件所有dependency全部安裝縱使其他packages有重複
- pnpm dlx會產生隨機快取，位置  
  `C:\Users\user\AppData\Local\pnpm-cache`
- pnpm清除快取  
  `pnpm cache delete`
- npm不安裝devDependencies
  `npm install --production`

### Windows路徑

- nvm windows本體安裝位置，安裝時需要提高權限  
  `C:\Users\user\AppData\Local\nvm`
- nvm windows，node安裝位置（包含全域npm套件）  
  `C:\Users\user\AppData\Local\nvm\版本`
- nvm node.js 連結（Windows）  
  `C:\nvm4w\nodejs`
