## MySQL

使用mysql client程式需求

1. [mysql - Official Image | Docker Hub](https://hub.docker.com/_/mysql)
2. Pull image  
   ```PowerShell
   docker pull mysql:8.4.7
   docker pull mysql:lts
   ```
3. Run Image與掛載ini檔案  
   ```PowerShell
   docker run --rm --name mysql-server -e MYSQL_ROOT_PASSWORD=your_password -v .\_env\POS-Fengshan-sync.ini:/tmp/config.ini -p 3306:3306 -d mysql
   ```  
   說明：如沒有 Image會自動 pull
4. 執行 MySQL Client  
   ```PowerShell
   # 進入互動式 mysql client
   docker exec -it mysql-server mysql --defaults-file=/tmp/config.ini
   # 非互動式
   docker exec -t mysql-server mysql --help
   ```
5. 結束  
   ```PowerShell
   docker rm mysql-server --force
   docker volume prune -f
   ```
